**Travel & Trip Project**, kullanıcıların seyahat rotalarını, gezi yazılarını ve deneyimlerini inceleyebileceği; yöneticilerin ise içerikleri dinamik olarak yönetebildiği modern bir **ASP.NET MVC Web Uygulamasıdır**.

---

## 📌 Proje Özellikleri ve Modüller

Proje, kullanıcı tarafı (UI) ve yönetim tarafı (Admin) olmak üzere 2 ana yapıdan oluşmaktadır:

### 🌐 Kullanıcı Tarafı (UI)
* **Ana Sayfa:** Popüler seyahat rotaları, öne çıkan bloklar ve dinamik slider alanı.
* **Bloglar:** Gezi yazılarının listelendiği, detaylarının okunabildiği ve yorum yapılabildiği dinamik alan.
* **Galeri:** Gezilen yerlere ait fotoğrafların sergilendiği görsel modül.
* **Hakkımızda & İletişim:** Site ve yazarlar hakkında bilgi veren, ziyaretçilerin mesaj gönderebileceği iletişim formu.

### ⚙️ Yönetim Paneli (Admin Panel)
* **Blog Yönetimi:** Yeni seyahat/blog yazısı ekleme, düzenleme ve silme (CRUD) işlemleri.
* **Yorum Yönetimi:** Ziyaretçiler tarafından yapılan yorumları onaylama, düzenleme veya kaldırma.
* **İçerik & İletişim Yönetimi:** Hakkımızda metinlerini güncelleme ve gelen iletişim mesajlarını görüntüleme.

---

## 🛠️ Kullanılan Teknolojiler

* **Backend:** C#, ASP.NET Core MVC
* **ORM:** Entity Framework Core (Code First / DB First Approach)
* **Veritabanı:** MS SQL Server
* **Frontend:** HTML5, CSS3, Bootstrap, JavaScript, jQuery
* **Mimari:** Model-View-Controller (MVC)
